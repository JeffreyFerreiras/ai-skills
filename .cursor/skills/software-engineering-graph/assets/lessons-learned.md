# Supervisor lessons learned

This journal carries reusable, evidence-backed lessons across graph runs. The Supervisor reads it
before scoping each new run and updates it during or after a run when a finding would change a
future decision. Keep entries short. Do not store secrets, private user data, raw session content,
or unverified conclusions.

## Lessons

For each lesson, record:

### Short decision-oriented title

- **Context:** When the lesson applies.
- **Lesson:** What the Supervisor should do differently.
- **Evidence:** Run ID and a safe artifact, command, or outcome reference.
- **Recorded:** YYYY-MM-DD.

Replace this example structure with actual lessons. Correct an existing entry when new evidence
changes it; do not accumulate contradictory advice.
