# Focused production preflight

Apply these checks in existing gates and three-round budgets. They add no user
checkpoint or permission to regenerate media. Keep
[production context and review bindings](production-context.md) with existing
records. For NotebookLM, use observed controls and accessible outputs; local
narration/encoding commands do not control vendor output.

## Lock meaning before expensive production

Lock one teaching objective, selected realistic example, claim scope, narration
and storyboard through independent script review before TTS/rendering or upload
for generation. Use existing [TEACH-OPEN-01 evidence](teaching-opening.md), without
a second rubric. Keep approved script/example/voice choices authoritative.

At the existing script/sample decision, consolidate foreseeable bounded allowance
choices for narration, cover, encoding and delivery repairs. Record exactly which
limits the user grants, their scope and already consumed work. Existing explicit
grants control; do not add an optional checkpoint. Elapsed waiting or feedback
never grants approval, renews an allowance or resets a spent budget.

Record pronunciation separately from display spelling and alignment tokens:
canonical term, spoken form, occurrence/context and approved voice/engine. Audition
ambiguous names/acronyms before the full take. Verify actual encoded speech later.
Pronunciation changes invalidate affected narration, cues, timing and downstream
evidence within spent budgets. Preserve accepted performance; never trim, stretch
or resynthesize it to fix layout, export size or loudness.

## Try the wrong reading early

Have independent visual/logical reviewers test plausible wrong readings: similar
actors confused; retry mistaken for a new item; an object changing identity;
success inferred before acknowledgement; end state contradicted by captions.
Inspect before/action/after and continuous motion where available. Require visible
identity anchors, supported connectors, causal order and explicit outcome. A plan
or frame sample cannot prove unseen motion. Record playback/listening gaps.

Inspect captions over the densest actual frames and moving objects, including
entry/exit and reveals. Verify clearance, contrast and readable holds at delivery
size. A layout declaration cannot establish visual clearance.

When a cover is requested, settle title hierarchy and focal subject early. Derive
safe regions from the actual supported destination; inspect full cover and actual
thumbnail/crop previews before expensive variants. Do not invent a universal
margin percentage or assume a centered source survives every crop. Preserve the
existing original-reference and independent full-cover/thumbnail approval gate.

If repeated image generation misses exact approved cover text, layout or margins,
preserve accepted illustration elements. Generate only needed illustration and
compose approved text/layout deterministically with available local tools. Check
a cheap actual thumbnail/crop at the intended viewing size against measured
destination safe regions before expensive variants, then use the existing
independent full-cover/thumbnail acceptance. This focused remedy uses the current
cover reservation; a template or layout declaration cannot prove crop readability.

## Inspect the encode and destination

Bind AAC QA to exact final output hash/settings, approved input WAV hash, stream
metadata, diagnostic output and actual listening receipt. Measure the decoded
encoded stream for clipping and peak/true-peak headroom with existing available
tools; codec conversion can introduce peaks. Use existing delivery targets, not
invented universal loudness numbers. WAV success cannot approve AAC. Gain-only
correction preserves accepted performance and requires fresh encoded QA. Missing
diagnostics/listening remain scoped gaps.

For an affected local stereo AAC path, the successful linked-channel configuration
is forced mid-side enabled, intensity stereo disabled and PNS disabled. Use it as
a path-specific tested starting configuration through the actual encoder's
supported interface, recording its real settings without inventing flags. Verify
actual encoded channels, measured encoded headroom and listening on the exact
output before acceptance. Preserve the approved WAV and performance; do not apply
universal gain or change speech timing. Unsupported controls or missing channel,
measurement or listening evidence leave acceptance pending within the existing
budget. Other encoders and NotebookLM use their own supported controls and actual
output verification; these local options do not become their defaults.

Round-trip UTF-8 scripts, captions and manifest text through actual tool boundaries.
Verify non-ASCII display/pronunciation text survives; never silently strip it or
confuse alignment spelling with spoken form.

Before expensive export, confirm the requested channel supports the actual
container/file/size and authorized destination. Keep approved continuous master,
requested review copy and their evidence identities distinct. Verify actual
supported transfer/destination when performed. Rendered, QA-passed, delivered,
accepted and published remain distinct. A local path is not a completed transfer.
Use the actual selected channel/skill contract to verify an available transfer
method. Before replacing an existing delivery, verify its exact identity and
current version through that contract's supported guard; unavailable protection
leaves replacement pending. Preserve original delivery identities and immutable
receipts. If text needs UTF-8 conversion for inspection, derive a separate
observation with the original receipt's identity/hash and conversion provenance;
never rewrite the original receipt or treat the derived text as the original.
Keep private media/receipts/source content in the authorized project, outside
installed skills and public guidance.
