# Production record

Presentation requirements are not technical evidence. Copy this template into
the video project or use these fields in its existing record. Leave unperformed
checks pending; remove branches outside the requested deliverable.

## Brief and checkpoint

- Learning question, audience, what/problem/why/solution opening, ordered learning
  preview, concrete example, limits, and source/claim locators:
- Requested deliverable, format, duration constraint, style/reference identities:
- Voice engine/version, voice/rate, pronunciation choices, WAV/cue paths and hashes:
- Native prosody, synthetic reference/transcript/hash and provenance, model/codec
  revisions and dtypes, staged loading, fallback reason, measured timing scope:
- Configurable model/runtime/cache roots, any scoped relocation/junction tests
  and rollback evidence; configured finished-video destination:
- Accepted choices, local/external authorization, any reserved sample decision:
- Spec and scene source revision/hashes, assets/fonts/licenses, dependency lock:
- Render entrypoint, exact commands, output paths, unit/frame ranges and hashes:
- Resume method, completed units, invalidated inputs, next action:

## Review ledger

Repeat per deliverable stage, retaining previous rounds and finding IDs.

- Stage, candidate path/hash, scene IDs/time range, round number, reviewer identity:
- Technical verdict and source/contract evidence:
- Editorial verdict and native-speed playback/listening coverage:
- Visual verdict, reference comparison, encoded size and scene/transition coverage:
- Dedicated visual reviewer per scene, scene ID/time range, establishing/mechanism
  keyframes, motion/transition evidence, round count, findings, and outcome:
- Evidence paths, exact sampled frames, played/listened intervals, uninspected scope:
- Finding ID, observed issue, impact/severity, focused fix, revised hash, verification:
- Remaining requirements/limitations and next permitted action:

## Final media and delivery

- Encoded identity/hash, dimensions, fps, codecs/channels, frame count/duration:
- Full-decode result and command; audio/video start/end and sync tolerance:
- Integrated LUFS/true peak dBTP, channel convention, target/rationale, exact command:
- Any two-pass repair input/hash, measured filter values, remeasured output/hash:
- Distributed waveform windows/method/lags after repair; actual listening scope:
- Approved intro/body hashes and sample offsets, canonical-word reconciliation,
  ASR disagreements/uncertain boundaries, actual-waveform caption/anchor timing:
- Local handoff path or authorized transfer receipt, whole-file identity evidence:
- Any brief-authorized full-length 1080p chat preview or other requested copy:
  byte limit, measured size, audio preservation evidence,
  encoded visual/audio review, transfer evidence:

Track each state separately with evidence, pending requirements, and the exact
artifact revision. Rendering is not QA, transfer is not acceptance, and acceptance
is not publishing permission.
