# Video production lessons

Use the bundled [production lessons](references/production-lessons.md) before
planning and at closure. Read relevant past evidence, apply it within the current
brief, and save verified new lessons when current memory-write rules permit.
Keep one local journal across participating video and cover workflows.

For OpenArt or another externally managed video skill, use this companion beside
the selected production workflow. Record its tool and version with each lesson.
Do not edit the plugin cache or replace its approval, generation or review rules.
The companion itself does not generate, upload, publish or regenerate media.

The learning-video and TikTok skills bundle this same protocol. When one already
loaded it, reuse the same journal path and task record without a second pass or
duplicate entries. A standalone installation needs no sibling skill.
