# Research TikTok hashtags for the video

## Define what the viewer is looking for

Use the video, script, or brief to identify the precise subject, what the video
actually teaches or shows, the likely viewer query, and the intended audience
and language. Record the target region when it matters. Infer from supplied
context where possible and mark material assumptions. Ask only if a missing
detail would materially change the recommendation and cannot be inferred.

Generate candidates from the exact subject, useful synonyms, and closely
related audience interests. Search both natural-language queries and exact
hashtags. Include plausible alternatives to any existing set. Check ambiguous
tags against what their results are about.

## Gather comparable evidence

- Start with [TikTok Creative Center Trends](https://ads.tiktok.com/resources/help/article/how-to-use-trends)
  for hashtag activity and related videos. Use
  [Creator Search Insights](https://support.tiktok.com/en/using-tiktok/growing-your-audience/creator-search-insights)
  when legitimately available to check the matching search topics and any
  content-gap signal. Tie each topic to the relevant viewer query. A signal
  for a topic does not measure searches for its corresponding hashtag.
- Inspect public TikTok posts or tag results for relevant and off-topic uses.
  If needed, use accessible public sources that show actual TikTok post
  captions or tags and label indirect evidence. Before inspecting a result
  list, choose a small consecutive sample, such as the first five distinct
  inspectable posts per tag in the displayed order. Record the query, filters,
  order, sample size and examples, and note unavailable results. A search
  sample shows how tags are used. Ranking, indexing, and personalization can
  affect what appears, so avoid treating the sample as representative.
- Use the target region and language filters where available. Label unknown
  or unmatched geography or language as context and exclude it from
  comparisons for the target audience.
- For each observation, record the source URL, retrieval date, language or
  region when known, and applicable window. For a number, record its exact
  metric label and definition or unit as displayed. Mark an unstated scope
  or definition as unknown. Hashtag post counts show tagged supply within
  their stated scope. Keep them distinct from query demand, impressions,
  views, and engagement. Compare values only when the source, definitions,
  scope and windows support it. Use competition evidence only where it
  relates to the same viewer intent. Generic platform guidance explains
  features but cannot validate a tag set.
- If analytics redirect, require unavailable access, or display no usable
  metrics, record the gap and continue with accessible public research.
  Follow the skill's account and access limits. If no relevant TikTok usage
  can be observed, topical sources may still clarify terminology and fit.
  Do not infer a zero count from an unavailable result.

## Choose and report the tags

Give a compact table for the candidates considered, including rejected tags.
Shared observation dates or filters can go above the table.

| Tag and decision | Fit to this video and viewer query | What was observed, source and scope | Limitation and confidence |
| --- | --- | --- | --- |

Name the kind of evidence in each row when available: editorial fit, observed
usage, quantitative popularity, or measured account performance. State what
the confidence applies to and why, such as strong topical fit with demand
unknown. Use words, without invented scores. Treat performance of other
posts, even posts with the same tags, as evidence about those posts.

Prefer the tags that best match the content and viewer intent. Use comparable
demand or supply evidence to weigh close alternatives when available. Include
a broad tag only if it serves a relevant viewer intent that merits a slot.
Three to five lowercase tags is an editorial preference. Use fewer if only
fewer are justified. Avoid routine reuse across topics. When evidence only
supports fit or example usage, label the recommendation relevance-based and
name the missing metrics. Give the paste-ready tags with the caption if
requested. Put the table, brief rationale, and sources in the research notes.

## Test after publication when useful

Propose a hypothesis and choose one primary outcome that the authorized
analytics can report, such as views from TikTok Search if exposed. Define
the measurement window from publication before comparing posts. Record each
tag set, topic, creative, audience, posting time and any promotion. Compare
similar posts at equal post ages and account for differences when interpreting
results. Call this observational when the tag sets were not assigned under
a controlled design. For a controlled experiment, specify what is randomized
and keep other conditions comparable. Report uncertainty and avoid claiming
that tags caused a change without evidence to support it. Use authorized
account data only. A proposal does not authorize publishing or account changes.
