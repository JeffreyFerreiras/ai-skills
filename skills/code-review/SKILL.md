# Code Review

Review the local changes against the master branch.
Use git diff to identify code changes.
Provide constructive feedback on code quality, style, correctness, and adherence to best practices.
Focus on areas such as readability, maintainability, performance, and security.
Suggest specific improvements or refactoring where applicable.
Highlight any potential bugs or logical errors.
Ensure that the code aligns with the project's coding standards and guidelines AGENTS.md.
Provide feedback in a clear and organized manner, referencing specific lines or sections of the code when necessary.
