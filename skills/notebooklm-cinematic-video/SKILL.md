# NotebookLM cinematic video

Create one coherent longer-form learning video through NotebookLM, with a detailed
production document and a separate concise activation prompt. For a packet-only
request, deliver those reviewed files without uploading or generating.

Read the bundled [NotebookLM workflow](references/notebooklm-workflow.md) for
source preparation, review, upload/activation, duplicate checks and delivery.
Use the [scene director](references/scene-direction.md) before storyboard lock.
The [inspected history](references/reference-history.md) distinguishes recovered
conventions from new defaults. All references ship with this skill; no sibling
skill installation or local voice/rendering engine is required.

For the established neon/chalk style, use [Neon Chalk Systems](references/neon-chalk-systems.md).
Its [Cloudflare case decomposition](references/cloudflare-cinematic-decomposition.md)
separates observed visual choices, approximate narrative structure and weaknesses
to repair; read it when a concrete cinematic reference would help scene planning.

Choose depth from the learning objective and available format. A recovered case
study aimed for 5-7 minutes where supported; this is an example, not a duration
guarantee or fixed target. Use chapters/beats for context, a concrete causal
journey, failure/tradeoff and synthesis. Define terms in ordinary language before
using them. Keep one idea in focus and enough time for each causal step. A longer
video is not permission for jargon, filler or several competing examples.

Ask the director to justify contextual scenes, visual metaphors, spatial changes,
before/after demonstrations and cutaways as useful. Require a purposeful fresh
transition scene and clear returns to readable technical views. Preserve object
identity, causal order, useful chalk/neon elements, accessible contrast and bottom
captions where supported. Cinematic does not mean rapid cuts or spectacle.

Keep factual/historical scope explicit in case studies and label illustrative
events. Select only the reviewed episode plan, relevant factual sources and the
applicable style source. Never upload this skill or review instructions as content.
Use only the observed NotebookLM controls for format, voice and output. Do not
promise exact aspect, length or script reproduction, or insert local Kokoro
commands/settings into the production packet.

Carry the common workflow's shared three-round review budget per deliverable,
exact artifact evidence and existing user-reserved decisions. Deliver one
continuous requested full video plus the production document, activation prompt,
source/scene handoff and scoped QA. Generation, delivery, user acceptance and
publication remain separate states.
