# NotebookLM short video

Create a digestible learning short through NotebookLM, using a reviewed production
document and a separate concise activation prompt. A document-only request ends
with those files; upload-only work ends with verified source ingestion.

Read the bundled [NotebookLM workflow](references/notebooklm-workflow.md) for
source preparation, review, upload/activation, duplicate checks and delivery.
Use the [scene director](references/scene-direction.md) before storyboard lock.
The [inspected history](references/reference-history.md) distinguishes the older
90-120-second template from the current 90-180-second brief. These references
ship with this skill; no sibling skill or local voice/rendering engine is needed.

Teach one core idea through one concrete example, a visible causal sequence and
one useful consequence or limit. Target 90-180 seconds according to content and
the episode brief, subject to actual NotebookLM capabilities. Start with an honest
spoken hook, quickly explain what/why, then show the mechanism in understandable
steps and finish with the answer. Cut secondary concepts before rushing speech.
Avoid dense jargon, artificial passage gaps, duration padding or a word-count
target that prevents the viewer understanding the result of each step.

Estimate runtime at natural teaching pace before production. If the topic needs
more than 180 seconds to teach clearly, warn with the estimated runtime and
reason, then ask the user to approve a longer runtime or choose a narrower/split
scope. Wait for the choice before upload for production or NotebookLM generation;
independent planning may continue. An existing explicit approval covering the
runtime satisfies this choice; do not ask again. Include the target and any explicit longer
runtime approval in both production document and activation prompt. Do not cram
or pad content. Inspect actual runtime: an unexpected output over 180 seconds
does not authorize longer delivery. Pause further generation/delivery, report the
overrun and obtain the same choice before proceeding. Preserve consumed review
rounds and invalidate affected approvals after scope/timing revisions.

Have the independent example-fit advisor compare 3-4 scenarios before drafting;
checkout/payment is not the default. The director evaluates scene approaches and
specifies a fresh, meaningful transition scene within the short's teaching flow.
It can be a compact before/after or contextual bridge in the same visual family;
do not consume the lesson with unrelated cinematic inserts or variety quotas.
Preserve recognizable objects, causal continuity, readable holds, bottom captions
where supported and accessible contrast.

Follow the common workflow's current-hash independent reviews and shared maximum
of three total rounds per deliverable. Native-paced teaching quality matters more
than exact timing compliance. Use NotebookLM's observed narration options; the
accepted local Kokoro voices/speed do not control its output. Record actual
runtime/aspect/caption/voice behavior and any deviation from the brief.

Deliver the production document and separate activation prompt, exact selected
source identities, scene-director handoff and scoped QA, plus the continuous short
and verified notebook/output link when requested and available. Keep generated,
delivered, user-accepted and published states distinct.
